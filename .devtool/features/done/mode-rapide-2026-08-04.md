# Mode rapide

Si le mode normal est terminé, alors débloquer le mode rapide (ajouter une étoile blue) et si le mode rapide et terminé alors débloquer le mode ultra-rapide (ajouter une étoile violette), puis unefois terminé alors débloqué le mode infini (qui va doucement puis de plus en plus rapide)
