Conditions d'utilisation

Version 0.3.0 — 28 août 2026

Glyphfall est un jeu gratuit et libre, qui enseigne le hangeul coréen, les kana et les premiers kanji japonais. Ces conditions décrivent ce que vous pouvez en faire et ce que nous ne garantissons pas.

Utilisation

Le jeu s'utilise sans compte, sans frais et sans limite. Il n'y a rien à accepter pour jouer, rien à acheter, et aucun service en ligne dont vous dépendriez.

Licence

Le code est publié sous GNU General Public License v3.0. Vous pouvez l'utiliser, l'étudier, le modifier et le redistribuer. Toute version modifiée que vous distribuez doit l'être sous la même licence, code source compris, et conserver les mentions d'auteur.

Les polices de caractères gardent la leur, la SIL Open Font License 1.1 ; leurs mentions sont reproduites dans le dépôt, dans assets/fonts/LICENCES.md. Les musiques sont produites par synthèse et libres de droits.

Absence de garantie

Le jeu est fourni tel quel, sans aucune garantie, comme le prévoit la licence. Il est un support d'apprentissage et non un ouvrage de référence : les prononciations et les moyens mnémotechniques sont des approximations pédagogiques, pas une transcription phonétique savante.

Vos données

Voir la politique de confidentialité : il n'y en a pas qui sortent de votre appareil.
