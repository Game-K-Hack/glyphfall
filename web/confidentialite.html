Politique de confidentialité

Version 0.2.1 — 28 août 2026

Glyphfall ne collecte aucune donnée personnelle. Ce n'est pas une promesse de bonne conduite : le jeu n'en a pas les moyens techniques.

Ce qui n'existe pas

  • Aucun compte, aucune inscription, aucune identification.
  • Aucune publicité, aucun traceur, aucune mesure d'audience.
  • Aucun achat, aucun paiement.
  • Aucune permission sur Android : ni réseau, ni fichiers, ni localisation, ni micro, ni caméra, ni carnet d'adresses. Vous pouvez le vérifier dans les réglages de votre téléphone.

Ce que le jeu enregistre, et où

Votre progression — niveaux réussis, étoiles obtenues, signes acquis, réglages de volume — est conservée sur votre appareil, et nulle part ailleurs :

  • dans le navigateur, par le stockage local du site, comme le ferait n'importe quelle page ;
  • sur ordinateur et sur téléphone, dans le dossier de données de l'application.

Rien n'en sort. Ces données ne sont ni transmises, ni consultées, ni partagées, ni vendues, parce qu'aucun code du jeu ne sait ouvrir une connexion réseau.

Pour les effacer : videz les données du site dans votre navigateur, ou désinstallez l'application.

Les enfants

Le jeu convient à tous les âges. Comme il ne collecte rien, il ne collecte rien des enfants non plus.

Nous écrire

Pour toute question sur cette politique : le suivi du dépôt.
